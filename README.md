# ลอยกระทงและปล่อยโคมออนไลน์ 3D ณ พระเจดีย์กลางน้ำ ระยอง 🪷🏮
**Loy Krathong & Lanna Sky Lantern 3D WebGL Online Festival**

เว็บแอปพลิเคชัน 3D WebGL สำหรับร่วมเทศกาลลอยกระทงและปล่อยโคมลอยออนไลน์ จำลองบรรยากาศงานวัดยามค่ำคืน ณ **พระเจดีย์กลางน้ำ โบราณสถานคู่เมืองระยอง**

---

## ✨ ไฮไลต์และฟีเจอร์เด่น (Key Features)

### 1. 🏛️ ฉากจำลอง 3 มิติ แลนด์มาร์กเมืองระยอง (3D Rayong Landmarks)
- **พระเจดีย์กลางน้ำ ระยอง (Phra Chedi Klang Nam):** เจดีย์ทรงระฆังคว่ำสีขาวทองอร่าม โบราณสถานสำคัญกลางปากน้ำระยอง พร้อมระบบไฟสปอตไลต์ส่องสว่าง
- **สะพานข้ามคลองดีไซน์โค้ง (Arched Bridge):** สะพานไม้ข้ามคลองพร้อมราวระเบียง โคมไฟหัวเสา และไฟประดับสีทองสะท้อนผิวน้ำ
- **บรรยากาศงานวัดไทย (Temple Fair):** ชิงช้าสวรรค์ 3D หมุนตลอดเวลาพร้อมกระเช้าถ่วงน้ำหนักและไฟ LED นีออนวิ่งสลับสี, ซุ้มประตูวัดเรืองแสง, และซุ้มเกมงานวัด
- **ต้นไม้ใหญ่ริมน้ำและไฟหิ่งห้อย (Thai Sacred Trees & Fireflies):** ต้นโพธิ์และต้นจามจุรีใหญ่แผ่กิ่งก้านรอบวัด พร้อมไฟหิ่งห้อยหยดน้ำสีเหลืองทองระยิบระยับ
- **เรือหางยาวประดับไฟ (Long-tail Boat):** ลอยลำแล่นผ่านสายน้ำระยองอย่างสมจริง

### 2. 🪷 ระบบตกแต่งกระทง 3D (3D Krathong Customizer)
- **ฐานกระทง 4 สไตล์:** ใบตองพับกลีบผกาซ้อน 2 ชั้น, ดอกบัวหลวงบานสะพรั่ง, กะลามะพร้าวแกะสลัก, และเต่าขนมปังรักษ์น้ำอาหารปลา
- **ดอกไม้ไทยมงคล:** ดาวเรืองทอง, บานไม่รู้โรย & รัก, พุดซ้อนมะลิ, และบัวสัตตบงกช
- **เครื่องแขวนและของมงคล:** อุบะมาลัยดอกรักห้อยข้าง, ป้ายอวยพร & ธงสามเหลี่ยมมงคล
- **ธูปเทียนทอง:** ธูปทอง 3 ดอกพร้อมหัวไฟเรืองแสง เทียนมงคล 5 สี และเปลวไฟ 3D

### 3. 🏮 ระบบตกแต่งโคมลอย 3D (3D Sky Lantern Customizer)
- **รูปทรงโคมล้านนา:** ทรงกระบอกดั้งเดิม, ทรงบัวล้านนา, และทรงเพชรแปดเหลี่ยม
- **สีกระดาษสาโปร่งแสง 5 เฉดสี:** ขาวนวล, เหลืองทอง, ส้มแสด, ชมพูบัว, แดงชาด
- **ลวดลายไทยประยุกต์:** ลายกนกเปลวเพลิง, ลายประจำยาม, ลายจันทร์ & ดาว, และผิวกระดาษสาธรรมชาติ
- **หางริบบิ้นและพู่ห้อย:** ริบบิ้นผ้าไหมคู่พลิ้วไหวตามแรงลม, พู่ห้อยลูกปัดทองล้านนา

### 4. 🎆 ลูกเล่นโต้ตอบและการแสดงผล (Interactions)
- **หมุนมุมกล้อง 3D อิสระ 360°** (OrbitControls)
- **จุดพลุ 3D:** ปุ่มจุดพลุเดี่ยว และปุ่ม "🎇 พลุชุดใหญ่" อลังการเต็มฟากฟ้า
- **สลับโหมดแสงสี:** โหมดไฟงานวัดหลากสี (Temple Fair) vs โหมดแสงจันทร์โรแมนติก (Moonlight)
- **กล่องขอพรอ่านคำอธิษฐาน:** แตะที่กระทงหรือโคมลอยในสายน้ำเพื่ออ่านคำขอพรและกดส่งหัวใจอนุโมทนา
- **ดนตรีไทยบรรเลงสด:** จำลองเสียงดนตรีวันลอยกระทงผ่าน Web Audio API Synthesizer

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Three.js (r128):** 3D WebGL Rendering, Procedural 3D Geometries & Shaders
- **OrbitControls:** 3D Camera Manipulation
- **HTML5 Canvas & WebGL:** Procedural Canvas Textures (Kanok & Prajamyam Thai patterns)
- **Web Audio API:** Real-time Thai Melody Synthesizer
- **Vanilla CSS3:** Modern Glassmorphism & Responsive Layout

---

## 🚀 วิธีเปิดใช้งาน (Run Locally)
เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ หรือรันผ่าน Local HTTP Server:
```bash
python3 -m http.server 8080
```
จากนั้นเข้าชมได้ที่ `http://localhost:8080`
